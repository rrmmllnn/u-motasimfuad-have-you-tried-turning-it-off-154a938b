A one-line program that writes a single funny line a hopeless tech support agent gives a desperate customer — a big presentation due in ten minutes, a screen gone black, and the classic fix offered with cheerful, total uselessness. Built for make.fun's "Have You Tried Turning It Off?" bounty.

## Run it

```sh
python3 main.py
```

It writes the line to `/output/entry.txt` and prints it.
